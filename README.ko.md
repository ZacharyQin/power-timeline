<h1 align="center">Power Timeline</h1>

> “내 Steam Deck 배터리 용량이 줄어든 걸까? 지금 완충하면 전기를 얼마나 저장할 수 있지?”
>
> “배터리를 다 어디에 쓴 걸까? 그냥 놔뒀을 때 얼마나 줄었고, 게임할 때는 얼마나 썼지?”

Power Timeline은 Steam Deck용 Decky 플러그인입니다. 배터리의 완충 용량과 설계 용량을 비교하고, 잔량 변화와 게임 실행, 절전 구간을 하나의 타임라인에 보여 줍니다. 배터리가 지금 얼마나 저장할 수 있는지 확인하고, 언제 전기를 썼는지 되돌아볼 수 있습니다. 페이지를 닫아도 기록은 계속됩니다.

이 그림은 전원을 연결한 상태의 빠른 접근 메뉴입니다. 현재 배터리, 작은 전력 흐름, 최근 24시간, 배터리 정보가 보입니다. 그림의 와트는 기기 전체 전력이 아닙니다.

<h2 id="what">보이는 것</h2>

**지금 배터리는 얼마나 저장할 수 있을까?**

현재 완충 용량, 설계 용량, 두 값의 비율을 비교해 배터리 용량이 줄었는지 판단할 때 참고할 수 있습니다. 여기서 보는 것은 완충했을 때 저장할 수 있는 양이지, 지금 남아 있는 잔량이 아닙니다.

**그냥 놔뒀을 때와 게임할 때, 배터리는 어떻게 줄어들까?**

최근 1일, 3일, 7일의 잔량 변화를 게임 실행, 전원 연결 변화, 절전 구간과 함께 볼 수 있습니다. 어느 구간에서 많이 줄었는지, 그때 무엇을 하고 있었는지 되돌아볼 수 있습니다. 절전 구간은 전후 잔량을 비교할 수 있지만, 그동안 연속 측정하거나 사용 에너지를 보충 계산하지 않습니다. 게임 기록에서는 각 게임의 에너지 추정도 볼 수 있습니다.

빠른 접근 메뉴(QAM)에서는 현재 잔량, 작은 전력 흐름, 배터리 정보를 보고 Steam의 충전 제한을 켜거나 끌 수 있습니다. 충전 중이고 시스템 추정이 있으면 완충까지 대략 얼마나 걸리는지도 볼 수 있습니다.

<h2 id="install">설치</h2>

### 먼저 Decky 설치

Decky가 없으면 공식 [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader#installation) 안내를 따릅니다. 같은 안내는 [wiki](https://wiki.deckbrew.xyz/en/user-guide/install)에도 있습니다.

### 패키지 받기

[최신 Release](https://github.com/ZacharyQin/power-timeline/releases/latest)를 엽니다. 이름이 `power-timeline-`으로 시작하고 `.zip`으로 끝나는 파일을 받습니다. Source code (zip)은 받지 마세요. 그것은 소스이며 Decky에 설치할 수 없습니다.

다른 컴퓨터에서 ZIP을 받았다면 먼저 Steam Deck으로 복사합니다.

### Decky에서 설치

아래 메뉴 이름은 Decky 한국어 화면의 문구입니다. 이 플러그인은 스토어에 없으므로 ZIP으로 설치합니다.

1. 빠른 접근 버튼을 누르고 메뉴를 연 뒤 플러그 아이콘으로 이동합니다. 제목은 Decky여야 합니다. 이미 어떤 플러그인 안에 있으면 제목 왼쪽 화살표로 Decky가 나올 때까지 돌아갑니다.
2. 톱니바퀴를 고릅니다. 안내는 "Decky 설정 열기"입니다.
3. "일반"을 엽니다. "기타"에서 "개발자 모드"를 켭니다.
4. 왼쪽 목록에 "개발자"가 나타납니다. 그것을 엽니다.
5. "서드파티 플러그인"에서 "ZIP 파일에서 플러그인 설치"를 찾고 "검색"을 고릅니다.
6. Decky가 이 플러그인을 검토하지 않았다는 안내가 나옵니다. 처음에는 약 5초를 기다려야 계속할 수 있습니다.
7. 이름이 `power-timeline-`으로 시작하는 ZIP을 고릅니다.

설치한 뒤 플러그 아이콘 아래 목록으로 돌아가 **Power Timeline**을 엽니다.

백엔드는 하드웨어를 읽기 위해 root로 실행됩니다. 시스템 전원 정책을 스스로 바꾸지 않고, 다른 플러그인도 바꾸지 않습니다.

### 업데이트와 제거

업데이트할 때는 같은 최신 Release 페이지에서 새 `power-timeline-` ZIP을 받아 위 단계로 다시 설치합니다.

제거는 Decky 설정의 "플러그인"에서 합니다. 제거해도 기록은 지워지지 않습니다. 기록은 보통 `~/homebrew/data/power-timeline/`에 있습니다. 기록까지 지우려면 그 데이터 디렉터리를 지울 수 있습니다.

<h2 id="try-it">처음 사용</h2>

1. 빠른 접근 메뉴를 열고 플러그 아이콘으로 이동한 뒤 **Power Timeline**을 고릅니다.
2. "최근 24시간"에 초점을 옮기고 확인 버튼(A)으로 배터리 타임라인을 엽니다.
3. 페이지 위에서 "최근 1일", "최근 3일", "최근 7일"을 고릅니다. 곡선에 초점을 옮기고 좌우로 시점을 봅니다. 그 시점의 잔량과 전력이 나옵니다. 게임을 기록 중이었다면 아이콘과 이름도 나옵니다.
4. "게임 기록"을 고릅니다.
5. 빠른 접근 메뉴로 돌아온 뒤, 작은 전력 흐름을 고르고 확인 버튼을 누르면 전력 흐름이 열립니다. "배터리"를 고르고 확인 버튼을 누르면 전원과 배터리가 열립니다.

처음 켜면 그 이전 기록은 없습니다. 켜기 전의 사용량도 채우지 않습니다.

<details>
<summary>터치와 다른 조작</summary>

- "최근 24시간"을 누르면 타임라인이 열립니다. 작은 전력 흐름을 누르면 전력 흐름이 열립니다. "배터리"를 누르면 전원과 배터리가 열립니다.
- 빠른 접근 메뉴의 24시간 작은 그림에서 좌우는 잠깐 표시만 옮기고, 타임라인으로 들어가지 않습니다.
- 타임라인 곡선에서는 가로로 밀어야 시점이 선택됩니다. 밀지 않고 누르기만 하면 선택되지 않습니다.

</details>

<h2 id="limits">알아 두기</h2>

- 기기 전체 전력은 배터리가 방전 중이라고 확인될 때만 알 수 있습니다. 전원을 연결한 동안은 알 수 없습니다. 충전 전력, 배터리 순 전력, APU 전력으로 대신하지 않습니다.
- 게임 에너지는 추정입니다. 게임 두 개가 동시에 실행 중이어도 각각 기기 전체 에너지를 받지 않습니다.
- 측정하지 못한 값은 알 수 없음으로 남고, 0으로 표시하지 않습니다. 완충까지 걸리는 시간은 시스템 추정이며, 정확한 카운트다운이 아닙니다.
- 충전 제한은 Steam에 이미 있는 스위치만 켜거나 끕니다. 퍼센트는 Steam에서 바꿉니다.
- 기록은 기기에 남고, 올리지 않습니다.
- Steam Deck 한 대(Galileo)에서 써 보았습니다. 다른 기종은 확인하지 않았습니다.

<details>
<summary>에너지 추정에 무엇이 들어 있나</summary>

게임 에너지 추정은 프로세스 활동으로 나눌 수 있는 CPU와 GPU 에너지입니다. 그 게임을 실행할 때의 기기 전체 에너지가 아닙니다. 화면, 따로 읽은 SoC 전력, 그 게임에 할당되지 않은 시스템 사용량은 포함하지 않습니다.

</details>

<h2 id="language">언어</h2>

직접 고르기 전에는 Steam 표시 언어를 따릅니다.

간체 중국어, 영어, 포르투갈어, 스페인어, 일본어, 한국어 중에서 고를 수 있습니다. 빠른 접근 메뉴와 각 페이지 맨 아래에 국기가 있습니다. 좌우 또는 가로로 밀면 강조만 움직입니다. 확인해야 바뀝니다. 안내는 그 국기의 언어입니다. 고른 언어는 기억합니다.

이 문서도 같은 여섯 언어입니다. 맨 위 링크로 바꿉니다.

<details>
<summary>소스에서 빌드</summary>

Node.js, pnpm, Python 3이 필요합니다.

```sh
pnpm install --registry=https://registry.npmjs.org
pnpm typecheck
pnpm build
python3 -m unittest discover -s tests -v
```

`pnpm build`가 프론트엔드를 만듭니다. 실행 파일을 ZIP에 넣은 뒤 설치합니다. 데이터베이스는 플러그인 디렉터리에 넣지 마세요.

</details>
